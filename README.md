# 살롱 예약 안내

하루 한 분 예약 정책과 이메일 예약 절차를 안내하는 한국어 반응형 웹페이지입니다.

- 운영 페이지: https://sandboxwork.github.io/salon-booking/
- 예약 문의: sandboxwork@proton.me
- HTML, CSS, JavaScript만 사용하며 설치·빌드 과정이 없습니다.
- 문의 양식은 메일 초안을 만들고 사용자의 메일 앱을 엽니다. 메일을 실제로 발송한 뒤 확정 회신을 받아야 예약이 완료됩니다.
- 입력 내용은 서버에 전송하거나 브라우저에 저장하지 않습니다. 분석 도구와 외부 폰트도 사용하지 않습니다.
- 고객 예약표나 계정 인증정보는 이 저장소에 포함하지 않습니다.

## 로컬 확인

이 디렉터리에서 `python3 -m http.server 8080`을 실행한 뒤 http://localhost:8080 에 접속합니다.

## 배포

GitHub Pages는 `main` 브랜치의 루트에서 배포합니다. 소스 변경을 `main`에 반영하면 다시 배포됩니다.

## 수정

화면 문구는 `index.html`, 디자인은 `styles.css`, 문의 메일 생성은 `script.js`에 있습니다. 문의 주소를 바꾸려면 HTML과 JavaScript의 주소를 함께 변경하세요. 예약 가능 여부는 이메일 회신으로 확인하며, 이 사이트는 실시간 예약 캘린더가 아닙니다.
